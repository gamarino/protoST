# protoST 0.4.0 — gate audits (run 2026-09-29)

The plan's Thursday gate was run early, while the author was away. Five
independent audits ran against the branch head binary; every silent wrong
result, crash or hang they found was fixed with a regression test before
this record was written, and every contradicted claim was corrected.

## 1. Adversarial Smalltalk semantics — round 1 (~400 probes)

Found and fixed (each with a test): a method body swallowing the next line;
class and float printing; block shadowing aliasing outer variables; built-in
collection subclasses losing their class; Fraction protocol; `whenAny:`
hanging; actor errors losing their class; missing compile-time checks;
class variables and class-instance variables; reflection; Time/Date/Random;
specific error classes; literal-array keyword selectors. Missing protocol
added in the kernel (two agent passes).

## 2. Adversarial Smalltalk semantics — round 2 (~700 probes)

Found and fixed: a `wait` inside a primitive-evaluated block in an actor
method breaking the method (now blocks and helps); top-level statements
silently swallowed by the method above; bit operations and division on
LargeIntegers (protoCore defects, worked around); Fraction/Float equality and
hashing; actor-proxy identity and printing; class-side reflection; symbols as
blocks; culled handlers; Pharo class-definition keywords; class redeclaration
keeping methods; REPL methods seeing earlier classes; heap ceiling message;
errors in Future callbacks; DNU receiver class names.

## 3. Claims versus documents (~110 probes)

33 findings, all addressed: test counts; performance claims (start-up
dominated; work-only ratios and the 2.1× parallel ceiling now reported);
`addBehavior:` and existing instances; short-symbol behaviour; `outer`
reclassified as not implemented; actor proxy exceptions; immutability
wording; absent classes listed in tutorial 14; method-body rules; K5 size;
traits wording; interop symbol claim narrowed; unverified installers marked;
talk materials. One real bug found here — brace arrays of 49+ elements
aborting — fixed.

## 4. Tests, CI and demos

Fixed: demos could pick up the installed 0.3.0 binary (now version-checked);
"verified" did not check timings (now required and sanity-checked); demo
output now streams; `cli_memory_bounded` passed on a crash; three REPL checks
could not fail; the conformance runner accepted crashes as expected errors,
matched error text on stdout and had no timeout; nine bare `EXPECT-ERROR`
tests now name their error. Actor tests: 480/480 repeated runs clean.

## 5. Whole-branch code review

Critical: a rejected actor Future could hold a freed exception (now rooted on
the actor). Important: missing GC pins (8 sites); `waitHelping` burying an
actor under one that waits on it (now detected) and unbounded helping depth
(capped); shared exception re-signalled by several waiters (copied per
waiter); kernel classes merged on redeclaration (only user classes reused);
static symbol caches; inlined loop-variable checks; integral-Float hashing.
Minor findings recorded in the ledger.

## Outcome

`ctest`: 1041/1041 at commit 7031212 (the final build). Demos: 20/20 each
on the packaged binary. Open items for the author are in the ledger and in
the morning report: protoCore defects, the CLI echo decision (D12b), and the
release steps that need the author (merge, push, tag, install).
